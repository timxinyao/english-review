# Phase 8 — Today 沉浸式答题改版

状态：planned（2026-09-28；设计与实施计划完成，代码待实施）

## 目标与范围

- 移动端 Today 一题一屏，题目和反馈滚动，操作/输入固定底部。
- 主动不会与答错共享按题型揭示的纠错反馈；主动不会直接按 fail 结算。
- 顶部按 pass/basic_pass/fail/未做呈现进度；「今日学习」按学习项去重并提供只读答题记录及坏题入口。
- 右上撤销图标只撤销最近一次作答；精确回滚，重新排一题，区别于标记坏题。
